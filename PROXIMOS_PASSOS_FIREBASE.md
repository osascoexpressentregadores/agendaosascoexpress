# PRÓXIMOS PASSOS NO FIREBASE

O config do Firebase já está dentro do index.html.

Agora falta:

## 1. Continuar no console
Na tela onde você está, clique em "Continuar no console".

## 2. Ativar Authentication
Menu esquerdo:
Build / Criação > Authentication

Depois:
Começar > Método de login > E-mail/senha > Ativar > Salvar

Depois vá em:
Usuários > Adicionar usuário

Crie um e-mail e senha de admin.

## 3. Ativar Firestore Database
Menu esquerdo:
Build / Criação > Firestore Database

Depois:
Criar banco de dados > Modo produção > Escolher região > Criar

## 4. Regras
Em Firestore Database > Regras, cole as regras do arquivo firestore.rules.

Antes de publicar, troque:
COLOQUE_SEU_EMAIL_ADMIN_AQUI

pelo e-mail admin criado.

## 5. Publicar site
Suba este index.html no GitHub Pages.

Depois faça login admin no site com o e-mail e senha criados no Firebase.
