# Escala Oficial OE — Versão Premium Produção

## Direção do projeto
Esta versão mantém a arquitetura funcional e refaz a camada visual para seguir as pranchas oficiais:
- Kauan oficial
- Campanha Reservas OE
- branco limpo
- preto forte
- vermelho como ação
- cards premium
- leitura mobile-first

## O que está incluído
- Busca real por nome
- Resultado com horários
- Pontos/clientes
- Confirmação no WhatsApp
- Admin com login admin / senha 1212
- Edição de ponto, motoca, horário, vaga aberta
- localStorage
- Exportar/importar JSON
- Layout com rolagem natural, sem 100vh travando conteúdo

## Observação GitHub Pages
Como o GitHub Pages é estático, as edições ficam salvas no navegador usado pelo admin.
Para levar para outro dispositivo, exporte/importe o JSON.
