# Check admin adicionar escala

Correção aplicada para remover confusão visual no admin.

Antes:
- Dia, filtro, select, horário, ponto, status e botão ficavam embolados na mesma linha.
- O select ficava cortado.
- Parecia que o sistema não sabia se era filtro ou seleção.

Agora:
1. Dia e status ficam no passo 1.
2. Entregador fica no passo 2.
3. Horário e ponto opcionais ficam no passo 3.
4. Botão fica grande e separado.
5. Quando digita um nome existente único, o sistema seleciona automaticamente.
6. Se o nome não existir, ele abre o fluxo de novo entregador.
7. Mostra um aviso claro do entregador selecionado.
