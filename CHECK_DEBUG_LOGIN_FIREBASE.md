# Debug de login Firebase

Esta versão mostra o código real do erro de login na própria tela.

Códigos comuns:

- auth/unauthorized-domain: adicione o domínio do GitHub Pages em Authentication > Configurações > Domínios autorizados.
- auth/operation-not-allowed: ative Email/Senha em Authentication > Método de login.
- auth/user-not-found: crie o usuário em Authentication > Usuários.
- auth/wrong-password ou auth/invalid-credential: e-mail ou senha digitados errado.
- Firebase ainda conectando: aguarde alguns segundos ou confira se o site está online com internet.
